## Runtime source

One file under `crates/noyalib/src` changes (16 insertions, 2
deletions), plus the version line in `crates/noyalib/Cargo.toml`. No
`unsafe` code, no new dependency, and no filesystem, network, process
or environment access is added.

- **CST block literals.** `can_use_block_literal` in
  `cst/document.rs` now refuses a string holding a C1 control other
  than NEL, U+FFFE, U+FFFF or a byte order mark, the characters the
  v0.0.62 scanner refuses in a block scalar. Such a string falls
  through to the existing double-quoted spelling. The change only
  narrows when a block literal is chosen; it adds no new output form
  (noyalib#533).
