## Runtime source

Fifteen files under `crates/noyalib/src` change (229 insertions, 79
deletions). No `unsafe` code, no new dependency, and no filesystem,
network, process or environment access is added.

- **Byte order marks.** A new `ParserConfig::byte_order_marks_in_text`
  field (the struct is `#[non_exhaustive]`), on only in
  `serde_yaml_compat()`, reaches the scanner through
  `Parser::for_config` on every loader, the streaming deserializer and
  the CST builder. With it off, a BOM inside plain or block scalars,
  comments or directive lines is refused (YAML 1.2.2 production 27),
  with the error placed at the BOM. With it on, a BOM is text, and one
  opening a token after other text on its line starts a plain scalar,
  as libyaml reads it. Anchor names and tags refuse a BOM in every
  profile. Quoted scalars and document prefixes are unchanged.
- **Error paths.** Loader frame paths bracket sequence indices
  (`items[0].name`, was `items.0.name`); the compat shim prefixes a root
  index with `.` (`.[1]`), as serde_yaml 0.9 prints it. Path text is
  built only when an error is reported.
- **Features and dependencies.** The bench-only `compare-saphyr` feature
  and its optional `serde-saphyr` dependency are removed, as is the
  `yaml-spanned` dev-dependency; the benches moved to an unpublished
  workspace crate. Rust 1.89 floor unchanged.

## Verification

`cargo test -p noyalib --all-features` passed 7,413 tests, including the
yaml-test-suite run; clippy with warnings denied passed for std and
no_std builds; strict rustdoc, cargo-deny and cargo-vet passed. Fuzz
regression corpora replay clean, and 15-minute local campaigns of the
diff, roundtrip and compatibility targets found nothing after a harness
fix. Each satellite's suite passed against this core through a temporary
path patch. The Rust 1.89 floor failed once on a single-use lifetime,
fixed in `d65ac7a`; hosted CI and the full-family fuzz run on that
source are the remaining acceptance evidence.
