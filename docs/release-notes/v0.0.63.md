# noyalib-wasm 0.0.63

Release date: 2026-11-19. Remaining release-page sections are generated
at release time.

## Highlights ⭐️

* **Core 0.0.63**: the exact core pin moves to 0.0.63. The JavaScript API does not call the changed CST insert, and `setValue` already double-quotes these characters.
* **Browser test fix**: the installed-bundle browser checks share one 60-second deadline instead of 5 seconds per call, which slow CI runners exceeded.
* **Dependencies**: the github-actions group (#128), the shared core workflows from the v0.0.62 release, and a cargo-vet record of the core delta.
* **In lockstep with noyalib 0.0.63**, which fixes a CST insert that wrote a block scalar the parser refuses (noyalib#533, reported and fixed by @zoosky).
