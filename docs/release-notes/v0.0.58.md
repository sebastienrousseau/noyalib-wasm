# noyalib-wasm 0.0.58

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **In lockstep with noyalib 0.0.58**: the exact core pin moves to `=0.0.58`, so this release picks up the core's 0.0.58 fixes, including hardened CST edits, the scalar-size budget enforced on `!include` and `${...}`, and policy checks on every entry point.
* **MSRV 1.89**: the minimum supported Rust version is now 1.89.0 (was 1.86.0), the floor the whole noyalib family shares from this release. If you are pinned below 1.89, stay on 0.0.57.
