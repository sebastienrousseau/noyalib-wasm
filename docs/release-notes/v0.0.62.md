# noyalib-wasm 0.0.62

Release date: 2026-11-17. Remaining release-page sections are generated
at release time.

## Highlights ⭐️

* **Core 0.0.62**: the exact core pin moves to `=0.0.62`. Parsing a byte order mark inside plain text now throws, and error paths read `items[0].name`.
* **Panic hook wired**: the `console_error_panic_hook` feature installs the hook at module load, so a panic logs its message to `console.error` before the abort.
* **In lockstep with noyalib 0.0.62**, the family's release after 0.0.60 (v0.0.61 was folded in and never published).
