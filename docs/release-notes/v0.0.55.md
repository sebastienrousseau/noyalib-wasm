# noyalib-wasm 0.0.55

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **No more trapped instances**: `stringify` and `WasmDocument.setValue` refuse a value that contains itself or nests deeper than 128 levels with a JavaScript `Error`, where it used to trap the instance for good.
* **Depth-checked edits**: `WasmDocument.set` and `replaceSpan` throw on a deeply nested fragment instead of overflowing the stack.
* **In lockstep with noyalib 0.0.55**: the exact core pin moves to `=0.0.55`, so this release picks up every core change for that version, including limits enforced on every loader and linear-time parsing of long lines.
